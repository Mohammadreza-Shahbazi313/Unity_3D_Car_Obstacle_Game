# Unity 3D Car Obstacle Game

 A 3D car obstacle game developed with Unity.

## About the Project

 Unity 3D Car Obstacle Game is a gameplay-focused project where the player controls a car and tries to avoid obstacles while driving through the environment.

 This project was created to practice and demonstrate 3D game development concepts in Unity, including player movement, vehicle control, obstacle interaction, and gameplay mechanics.

## Features

 3D car movement and control
 Obstacle avoidance gameplay
 Interactive game environment
 Physics-based vehicle movement
 Third-person gameplay camera
 Simple and focused gameplay mechanics

## Built With

 Unity
 C#
 Unity Physics System

## Prerequisites

 Unity Hub
 A compatible Unity Editor version

### Installation

1. Clone the repository:

```bash
git clone https://github.com/abolfazlghasemi83/Unity_3D_Car_Obstacle_Game.git
```

2.Open the project using Unity Hub.
3.Open the main scene.
4.Press the Play button to start the game.

# Controls
Key	Action
W / Up Arrow	Move Forward
S / Down Arrow	Move Backward
A / Left Arrow	Turn Left
D / Right Arrow	Turn Right
